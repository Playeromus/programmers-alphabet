CSS









A Css rule is made of a Selector, and by a Declaration.
A Selector defines what element you wish to be modified by CSS.
A Declaration is the modification that you impose upon the element.

Each Declaration consist's of atleast 1 Property and 1 Value.
A Value defines the Property, it is what changes the Property of the Element.
A Property defines which part of the element you wish to change, such as:

    
   
  • accent-color
    • 
   
   (Specifies an accent color for user-interface controls, this example uses red)
   
  • align-content
    • 
   (Specifies the alignment between the lines inside a flexible container when the items do not use all available space)
   
  • align-items
    • 
    (Specifies the alignment for items inside a flexible container)
   
  • align-self
    • 
   (Specifies the alignment for selected items inside a flexible container)
   
  • all
    • 
   [Resets all properties (except unicode-bidi and direction)]

CSS ID Selectors






You can also have the Selector be an id, which you can input into any element in the body of the code.
An example being:

❮!DOCTYPE html>
❮html>
❮head>
❮style>
#para1 {
  text-align: center;
  color: red;
}
❮/style>
❮/head>
❮body>

❮p id="para1">Hello World!❮/p>
❮p>This paragraph is not affected by the style.❮/p>





Result














CSS Class Selectors






The Class Selectors selects an HTML element with a specific class attribute.
In other words you make the classes, the classes can include attributes such as: red, 60%, 50px, etc.
It works similiarly to id's, and may be used in the same way, although classes have more effects you may choose to use.
An example of a Class Selector being used:

  ❮!DOCTYPE html>
❮html>
❮head>
❮style>
.center {
  text-align: center;
  color: red;
}
❮/style>
❮/head>
❮body>

❮h1 class="center">Red and center-aligned heading❮/h1>
❮p class="center">Red and center-aligned paragraph.❮/p> 

❮/body>
❮/html>


Result

  
You can also specify that a specific element can be affected by a class.
An example using this:

  ❮!DOCTYPE html>
❮html>
❮head>
❮style>
p.center {
  text-align: center;
  color: red;
}
❮/style>
❮/head>
❮body>

❮h1 class="center">This heading will not be affected❮/h1>
❮p class="center">This paragraph will be red and center-aligned.❮/p> 
  

Result

  
You may also combine separated classes.
Such as:

  ❮!DOCTYPE html>
❮html>
❮head>
❮style>
p.center {
  text-align: center;
  color: red;
}

p.large {
  font-size: 300%;
}
❮/style>
❮/head>
❮body>

❮h1 class="center">This heading will not be affected❮/h1>
❮p class="center">This paragraph will be red and center-aligned.❮/p>
❮p class="center large">This paragraph will be red, center-aligned, and in a large font-size.❮/p> 

❮/body>
