CSS









A Css rule is made of a Selector, and by a Declaration.
A Selector defines what element you wish to be modified by CSS.
A Declaration is the modification that you impose upon the element.

Each Declaration consist's of atleast 1 Property and 1 Value.
A Value defines the Property, it is what changes the Property of the Element.
A Property defines which part of the element you wish to change, such as:

    
   
  • accent-color
    • 
   
   (Specifies an accent color for user-interface controls, this example uses red)
   
  • align-content
    • 
   (Specifies the alignment between the lines inside a flexible container when the items do not use all available space)
   
  • align-items
    • 
    (Specifies the alignment for items inside a flexible container)
   
  • align-self
    • 
   (Specifies the alignment for selected items inside a flexible container)
   
  • all
    • 
   [Resets all properties (except unicode-bidi and direction)]
