HTML







!DOCTYPE html


!DOCTYPE must always be used at the start. The purpose of this declaration is to help the site display correctly.

An example of using !DOCTYPE html:

    <!DOCTYPE html>
    <html>
    ...




html


html is an element that must be used at the start. It is the root element, which in simple words, means that it holds all the code together.

An example of using html:

    <!DOCTYPE html>
    <html>
    ...
    </html>




head


The head is used to contain the meta information about the HTML page. Which can be used to dictate that all the next elements that you input in the head, will be used in the same way for all other instances.

An example of using head:

    <!DOCTYPE html>
    <html>
    <head>
    <style>
    pre {
    font-size:50px;
    text-align:center;
    }
    </style>
    </head>
    ...
    </html>




title


The title can only be used in the head element. The title element gives your HTML webpage a title.

An example of using title:


    <!DOCTYPE html>
    <html>
    <head>
    <title>Programmers Alphabet</title>
    ...
    </html>

Result





body


The body element defines the webpage's body. Whatever code you put inside the body, will show up on the webpage.

An example of using body:


    <!DOCTYPE html>
    <html>
    <body>
    <h1>The element body</h1>
    </body>
    </html>




h1 - h6


The h elements creates a heading. The numbers indicate the size., the 1 is the biggest while the 6 is the smallest.

An example of using the h1 - h6 element:


    <!DOCTYPE html>
    <html>
    <body>
    <h1>The h1 element</h1>
    <h2>The h2 element</h2>
    <h3>The h3 element</h3>
    <h4>The h4 element</h4>
    <h5>The h5 element</h5>
    <h6>The h6 element</h6>
    </body>
    </html>

Result





p


The p element creates a paragraph. You cannot make the paragraph bigger by putting a number next to it like the h1 - h6 elements.

An example of using the p element:


    <!DOCTYPE html>
    <html>
    <body>
    <p>The p element</p>
    </body>
    </html>

Result





a


The a element is used to define HTML links.
  
An example of using the a element:


    <!DOCTYPE html>
    <html>
    <body>
    <a href="www.google.com">This is a link which sends you to the main page of Google</a>
    </body>
    </html>




href


href is used to identify the destination of the link.
  
An example of using the href element:


    <!DOCTYPE html>
    <html>
    <body>
    <a href="www.google.com">This is a link which sends you to the main page of Google</a>
    </body>
    </html>

Result

br


br is an element which adds a line of space withing the site.
  
An example of using the br element:


    <!DOCTYPE html>
    <html>
    <body>
    <img src="Black_Labrador.jpg" alt="A Black Labrador" width="104" height="142"
    <br>
    <p>Dogs can be great pets!</p>
    </body>
    </html>

Result





style


Style is an atribute which is used to add styles to an element. You may change the background color, text color, fonts, text size and text allignment.
  
An example of using the style atribute:


    <!DOCTYPE html>
    <html>
    <body>
    <p style="color:red;">This is a red paragraph.</p>
    </body>
    </html>




lang


Lang is an atribute which is used to declare the language of the website, used to help search engines and browsers.
  
An example of using the lang atribute:


    <!DOCTYPE html>
    <html lang="en">
    ...
    </html>




title


Title is an atribute which is used to define extra information, that information will only be displayed when you hover your mouse over the element that has a "title".
 
An example of using the title atribute:


    <!DOCTYPE html>
    <html lang="en">
    <body>
    <p title="I'm a tooltip">This is a paragraph.</p>
    </body>
    </html>

Result





hr


hr is an element which adds space towards the website like br does, altough it adds a line in its space instead of white space.
 
An example of using the hr element:


    <!DOCTYPE html>
    <html lang="en">
    <body>
    <h1>This is a heading.</h1>
    <hr>
    <p>This is a paragraph.</p>
    </body>
    </html>

Result





pre


pre is an element which works similiarly to p, but instead it preserves the spaces and line breaks and displays them.
 
An example of using the pre element:


    <!DOCTYPE html>
    <html lang="en">
    <body>
    <pre>This is a preformatted text.
    altough it looks similiar to a paragraph, it functions differently.
    The preformatted text preservers spaces and line breaks that i add during the code.</pre>
    </body>
    </html>

Result
